## Датасет
Файл с данными размещён в Google Drive. В качестве учебного датасета был использован открытый датасет, посвященный анализу компонентного состава при термической обработке углеродистых и низколегированных сталей. Датасет был взят с Kaggle. Данный датасет был собран на основе трех библиографических источников из металлургической литературы: Hollomon (1945), Grange (1956) и Penha (2010). В общей сложности он включает 1466 примеров с использованием 34 различных классов стали, среди которых по два сплава с разным химическим составом относятся к классам SAE 1065, SAE 4140 и SAE 4340.

- Ссылка на датасет: [ссылка на датасет](https://drive.google.com/file/d/1BtFPueekTleALZJKeWwrfsnWMtw-BuPj/view?usp=sharing)
- Формат: CSV
- Источник: Kaggle.com 
- Размер: 156 КБ
- Количество строк: 1466
- Количество столбцов: 17
- Типы признаков: Числовые (компонентный состав), категориальные (классы стали).
